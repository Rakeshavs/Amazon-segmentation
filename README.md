# Amazon User Segmentation using K-Means Clustering

This project performs customer segmentation on Amazon users based on their **Annual Income** and **Purchase Rating** using **K-Means Clustering**. It also applies the **Elbow Method** to determine the optimal number of clusters.

---

## 📌 Project Overview

- **Goal**: To segment Amazon users into distinct groups for better targeting and recommendations.
- **Method Used**: K-Means Clustering (Unsupervised Learning)
- **Dataset**: `amazon segmentation using kmeans (clustering).xlsx`

---

## 📊 Features Used

- **Annual Income (in INR)**
- **Purchase Rating**

---

## 🧠 Techniques Applied

- **Data Preprocessing**
- **K-Means Clustering**
- **Elbow Method** for optimal cluster selection
- **2D Visualization of clusters**

---

## 📦 Libraries Used

- `numpy`
- `pandas`
- `matplotlib`
- `scikit-learn`
